# Exercícios Manzano - páginas 27 a 66 - Java

Projeto organizado para abrir direto no VS Code. Cada arquivo Java é independente e possui seu próprio `main`.

## O que está incluído

- **Lista 02 - decisões (`if/else`)**: exercícios lógicos 1, 2 e 3 + programas **L02A até L02L**.
- **Lista 03 - repetição com `while`**: **L03A até L03L**.
- **Lista 04 - repetição com `do...while`** (equivalente ao `repita...até` do material): **L04A até L04J**.
- **Lista 05 - repetição com `for`**: **L05A até L05K**.
- **Aprendizagem**: triângulos, divisibilidade por 4 e 5 e exemplos de fatorial do capítulo.

Os códigos foram mantidos simples, curtos e didáticos. Nas listas de repetição, foi respeitado o tipo de laço solicitado no enunciado.

## Como executar no VS Code

1. Abra esta pasta no VS Code.
2. Abra o exercício desejado, por exemplo `Lista03_While/L03A.java`.
3. Clique em **Run** ou execute no terminal:

```bash
javac L03A.java
java L03A
```

> Observação: no exercício do tabuleiro de xadrez e no somatório de 15 fatoriais foi usado `BigInteger` para evitar estouro numérico.
