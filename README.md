# Exercícios de Lógica de Programação - Apostila Manzano

Repositório com a resolução dos exercícios da apostila **Estudo Dirigido: Algoritmos**, de **José Augusto N. G. Manzano**, implementados em **Java**.

## Sobre o projeto

Este repositório reúne exercícios desenvolvidos para praticar conceitos fundamentais de lógica de programação e algoritmos, utilizando a linguagem Java, com base no material **Estudo Dirigido: Algoritmos**, de José Augusto N. G. Manzano.
